## Project Overview

`esignal` is a Flutter multi-platform application (Android, iOS, Web, Linux, macOS). Currently in early scaffolding stage with minimal custom code.

## Common Commands

```bash
# Install/update dependencies
flutter pub get
flutter pub upgrade

# Static analysis (flutter_lints)
flutter analyze

# Run all tests
flutter test

# Run a single test file
flutter test test/widget_test.dart

# Run the app (requires connected device or emulator)
flutter run

# Build for a specific platform
flutter build apk        # Android
flutter build ios        # iOS
flutter build web        # Web
flutter build linux      # Linux
flutter build macos      # macOS

# Clean build artifacts
flutter clean
```

## Architecture

- **Entry point:** `lib/main.dart` — `main()` calls `runApp(MyApp())`
- **Tests:** `test/` — Flutter widget tests using `WidgetTester`
- **Platform folders:** `android/`, `ios/`, `macos/`, `linux/`, `web/` — platform-specific native code (generated by Flutter, rarely modified directly)
- **Linting:** `analysis_options.yaml` includes `package:flutter_lints/flutter.yaml`

All application Dart code lives under `lib/`. New features, screens, and business logic should be added there.
